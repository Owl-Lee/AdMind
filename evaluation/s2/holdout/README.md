# S2 sealed holdout set

This directory defines an evaluation-only holdout for paused-frame placement. It is deliberately separate from `evaluation/s2/manifest.json` and the calibration workflow.

## Rules

- `status` must remain `sealed-unreviewed` and `useForTuning` must remain `false`.
- Every `groundTruth` is `null`. The collection categories describe sampling strata, not product labels.
- Do not open model results for these frames, tune rules, select thresholds, or train against them before the candidate system is frozen.
- The four cross-source samples are the primary holdout. The two same-source `CHARGE` samples are correlated supplemental diagnostics and must not be reported as independent generalization evidence.
- After a candidate is frozen, the product owner may review the sealed frames in a separately versioned review artifact. Do not replace this manifest with those labels.

## Reproduction and verification

The extractor uses the repository's installed Playwright Chromium and a temporary loopback-only HTTP server with byte-range support. It reads only the authorized local video assets.

```bash
node scripts/extract-s2-holdout.mjs
node scripts/extract-s2-holdout.mjs --verify-only
```

The first command creates the manifest and six JPEG files when they do not exist. Once sealed, it re-extracts to memory and fails if any regenerated byte hash differs; it never silently overwrites the set. Determinism is byte-level on the same host with the same Chromium build and source bytes. The verification mode checks source hashes, frame hashes, dimensions, split counts, and the no-label/no-tuning invariants without decoding the videos.

All frames are 1280×720 JPEG derivatives of sources whose provenance and release basis are documented in `docs/ASSET_MANIFEST.md`.

# S2 封存留出集

本目录保存只用于评估的暂停帧留出集，并与 `evaluation/s2/manifest.json` 及标定流程严格分离。

## 规则

- `status` 必须保持 `sealed-unreviewed`，`useForTuning` 必须保持 `false`。
- 所有 `groundTruth` 均为 `null`。采集类别只是抽样分层，不是产品标准答案。
- 候选系统冻结前，不得根据这些帧查看模型结果、调整规则、选择阈值或训练模型。
- 4 张跨来源样本是主要留出集；2 张同源 `CHARGE` 样本只用于相关性较高的补充诊断，不得包装成独立泛化证据。
- 候选系统冻结后，产品负责人可以在另一个带版本号的审核文件中标注这些帧；不得用审核标签替换本清单。

## 复现与验证

抽帧脚本使用项目已安装的 Playwright Chromium，并临时启动只监听本机回环地址、支持字节范围请求的 HTTP 服务；它只读取已授权的本地视频。

```bash
node scripts/extract-s2-holdout.mjs
node scripts/extract-s2-holdout.mjs --verify-only
```

首次运行会创建清单与 6 张 JPEG。封存后再次运行只在内存中重新抽取；如果任意字节哈希不一致就失败，不会静默覆盖。确定性范围为同一主机、同一 Chromium 构建和相同源文件字节。验证模式不解码视频，只检查源哈希、帧哈希、尺寸、分组数量以及“无标签、不可调参”约束。
