## 一、项目定位

AdMind 是一个面向长视频平台的 AI 广告决策原型。它不是广告拦截器，也不是简单把大广告缩小，而是依次回答三个问题：

1. **S1 高潮避让：什么时候适合投放？**
2. **S2 暂停保护：暂停后要不要投、用什么形式、放在哪里？**
3. **S3 伦理保护：这个场景能不能投？**

核心原则：

> AI 负责提供“视频里发生了什么”的证据；AdMind 的确定性规则负责最终决定。商业压力不能越过伦理硬规则。

## 四、关键技术链路

```text
视频素材
  ↓
TwelveLabs 离线分析（S1 / S3）或 MediaPipe 当前帧分析（S2）
  ↓
标准化 JSON：时间段、标签、分数、风险与位置
  ↓
AdMind 确定性规则：播放器状态、伦理边界、素材形式、商业约束
  ↓
可执行广告计划：立即投、延后、小卡片、全屏或完全不投
  ↓
网页播放器执行，并把证据和决定显示给用户
```

必须坚持的表达边界：

- `0.95` 是模型证据分数，不是统计学 95% 置信区间，也不是保证校准过的正确概率；
- 张力 `9.0 / 10` 是一个分析片段共同使用的粗粒度结果，不是每一秒都独立计算出 90%；
- S2 只能观察当前网页和播放器事件，不知道用户脑内意图，也看不到用户切到了微信还是 Word；
- 网页演示读取缓存的 TwelveLabs JSON，因此访客不需要 API Key，也不会每次播放都花 API 费用；
- S3 的商业任务不能为了补量越过伦理规则。
